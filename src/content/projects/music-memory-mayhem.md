Music Memory Mayhem is a web game where players place songs on a timeline by release date.

## The challenge

We wanted to make it easier for people to compare when songs were released.

![The opening screen of Music Memory Mayhem](/media/dynwebb24/mmm-cover.png)

## What I made

The main interaction is a timeline where players place songs in release order.

## The result

- A playable prototype
- A responsive interface
- A short testing and iteration cycle
